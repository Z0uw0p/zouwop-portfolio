Field Notes.

An editorial system and reading app for a quarterly field journal.

Brief

A quarterly journal covering landscape and climate asked us to design an edition that works as well on a phone as it does in print — without the print becoming a souvenir of the app.

Approach

We designed print and screen from the same typographic spine: one grid, one set of weights, one voice. Long-form features got a slower, wider measure on screen and a quiet reading mode; the print edition kept the full photographic spread the material deserved.

Outcome

The relaunch shipped as a matched pair — print and digital — with a shared navigation and a reader that remembers where you stopped. Subscriptions grew off the back of the first issue, and the masthead now produces each issue inside the system we set, adding features without us.
