# zouwop-portfolio

Personal homepage/portfolio for **Zouwop** — built with [Astro](https://astro.build), deployed on Cloudflare Pages.

## Stack
- Astro (static)
- Cloudflare Pages (build + host)
- Cal.com (self-hosted booking)

## Local dev
```bash
npm install
npm run dev
```

## Build
```bash
npm run build   # outputs to dist/
```
